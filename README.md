# Portfolio

- `index.html` – sivu (ulkoasu ja toiminta)
- `content/site.json` – kaikki tekstit ja projektit (muokataan /admin-hallinnasta)
- `media/` – kuvat ja videot
- `admin/` – sivun hallinta (`osoite/admin/`), asetukset tiedostossa `admin/config.yml`

Muista vaihtaa `admin/config.yml`-tiedostossa rivi `repo:` omaan GitHub-käyttäjänimeesi ja repositorion nimeen.
Sivu toimii vain verkko-osoitteesta (esim. GitHub Pages), ei kaksoisklikkaamalla tiedostoa.
